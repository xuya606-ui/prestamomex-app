## 🎨 核心交付物速览

### 触达形式清单（12 种）
| # | 形式 | 优先级 | 关键约束 |
|---|---|---|---|
| 1 | Push 推送 | P0 | 单日 ≤ 3 条，9-21 时段 |
| 2 | 站内横幅 | P0 | 同时 ≤ 2 个 |
| 3 | 模态弹窗 | P0 | 单日 ≤ 1 条/类型 |
| 4 | 短信 | P0 | 单日 ≤ 2 条，含 CAT |
| 5 | 邮件 | P1 | 须含 unsubscribe 链接 |
| 6 | 站内 IM / WhatsApp | P0 | 催收 9-20 时段 |
| 7 | Toast 浮窗 | P0 | 自动消失 3-5s |
| 8 | Slide-up 抽屉 | P1 | 单日 ≤ 1 次 |
| 9 | 引导蒙层 | P1 | 每功能仅 1 次 |
| 10 | 状态栏/角标 | P0 | 99+ 上限 |
| 11 | 运营浮窗 | P1 | 同时 ≤ 1 个 |
| 12 | 桌面 Widget | P2 | 用户主动添加 |

### 触达结点清单（12 个生命周期结点）
注册 → 实名引导 → 绑卡引导 → 风控审核 → 审批结果 → 放款到账 → 还款前 → 逾期分级 → 复借邀请 → 流失召回 → 提额活动 → opt-in 授权

### 业务场景矩阵（12×12）
详见 `04-产品规划与设计思路.md` 第 3 节，共 **144 个交叉点**（✅ 强推荐 70+、⚠️ 可选 30+、— 不建议 40+），**关键交叉点覆盖率 100%**。

### 指标体系（5 层）
- **触达层**：触达率、打开率、点击率、转化率、关闭率
- **业务层**：注册-实名、首贷、复借、回收率、召回率
- **体验层**：关闭通知率、卸载率、评分、NPS
- **合规层**：CONDUSEF 投诉率、催收时段合规率、opt-in 完整率、ARCO 响应
- **运营层**：实时看板、AB 实验、灰度发布

## 🇲🇽 墨西哥合规要点（贯穿全文）

### CNBV（国家银行证券委员会）
- 现金贷公司须注册 SOFOM
- 合同须披露 CAT、年化、IVA
- 不得吸收公众存款

### CONDUSEF（用户金融服务保护委员会）
- 催收人员须在 REDECO 注册
- 用户有权随时提前还款
- 投诉须 30 天内答复

### LFPDPPP（个人数据保护法）
- ARCO 四项权利
- 营销必须 opt-in
- 隐私声明须主动勾选

### 催收时间规则
- 工作日 9:00 - 20:00
- 周末 10:00 - 18:00
- 节假日禁止催收
