## 2. 痛点详解（按严重度排序）

### 痛点 1 🔴 触达形式单一（严重度：★★★★★）

**问题描述**：
- 平台触达中 **Push 占比 80%+，短信 15%，其他形式（横幅 / 弹窗 / 站内 IM / 角标）总和不足 5%**。
- 缺少：Slide-up 抽屉、Toast 浮窗、引导蒙层、桌面角标、应用内 IM 客服、震动/铃声、桌面 widget、短信外呼组合、邮件等。

**场景佐证**：
- **场景 A**：用户进入首页，平台对"提额活动"仅靠 Push 一条带过，没有首页横幅 + 活动浮窗 + 个人中心 Banner 的组合，用户错过率 60%+。
- **场景 B**：用户在审批中，APP 切到后台，平台仅发 Push，用户可能因静音/勿扰而错过，结果 35% 用户会反复打开 APP 查看状态。
- **场景 C**：用户绑卡失败，没有 Toast + 弹窗 + 短信组合告知，仅在列表页显示一行小灰字，导致 40%+ 绑卡流失。

**业务影响**：
- Push 打开率从行业平均 18% 跌至 8%，CTR 直接腰斩。
- 重要结点的用户触达漏斗在"打开 Push → 进入 APP"环节流失 90%。

**根因**：
1. 历史迭代以"轻量改动"为主，没有重新设计触达矩阵。
2. 缺少全渠道运营 SOP，各业务线（风控/还款/营销）独立发 Push，没有整合。
3. 设计资源集中在新功能，对触达视觉资产投入不足。

**目标**：
- 6 个月内将触达形式数量从 3 种扩至 10+ 种，单一渠道占比降至 50% 以下。

---

### 痛点 2 🔴 触达结点覆盖不全（严重度：★★★★★）

**问题描述**：
当前触达结点集中在"还款提醒 + 审批结果 + 营销活动"三类，覆盖率 < 40%。**首贷前引导、审批中状态、复借邀请、流失召回、提额唤醒**等关键结点几乎空白。

**结点覆盖矩阵（当前 vs 行业最佳）**：
| 用户生命周期结点 | 当前覆盖 | 行业最佳 | 差距 |
|---|---|---|---|
| 注册成功 | ✅ Push | ✅ Push + 站内 + 邮件 + 短信 | 缺 3 种 |
| 实名认证 | ⚠️ 仅提示未完成 | ✅ 5 种组合引导 | 严重不足 |
| 绑卡引导 | ❌ 几乎无 | ✅ 弹窗 + 横幅 + 短信 + 客服 | 严重不足 |
| 风控审核中 | ❌ 无 | ✅ 状态页 + Toast + Push + 进度条 | 完全缺失 |
| 审批通过/拒绝 | ⚠️ 仅 Push | ✅ Push + 站内 + 短信 + IM | 缺 3 种 |
| **放款到账** | ❌ 无 | ✅ 弹窗 + Push + 短信 + 站内 | 完全缺失 |
| **首贷前 7 日/3 日/1 日** | ❌ 无 | ✅ Push + 邮件 + 横幅 + 任务 | 完全缺失 |
| 还款前 3 日/1 日/当日 | ✅ 短信+Push | ✅ 5 种组合 | 缺 3 种 |
| 逾期 1 - 7 日 | ⚠️ 短信 | ✅ 短信 + Push + IM + 邮件 | 缺 3 种 |
| 逾期 7 - 30 日 | ✅ 高频短信 | ✅ 短信 + IM + 邮件 + 站内 | 缺 3 种 |
| 逾期 30+ 日 | ⚠️ 委托催收 | ✅ 委托 + 站内 + 邮件 | 缺 2 种 |
| **复借邀请（D+3/7/15/30）** | ❌ 无 | ✅ Push + 横幅 + IM + 短信 | 完全缺失 |
| **流失召回（30/60/90 天）** | ❌ 无 | ✅ Push + 短信 + 邮件 + IM | 完全缺失 |
| 提额/活动期 | ⚠️ 偶发 Push | ✅ 横幅 + 浮窗 + 落地页 + Push | 缺 3 种 |
| 合规 opt-in 授权 | ⚠️ 单点弹窗 | ✅ 多触点 + 教育页 | 缺 3 种 |

**场景佐证**：
- **放款到账是用户情感高峰**，但当前无任何特殊触达，用户感知弱。
- **复借邀请 100% 缺失**，意味着所有还款完成用户被动等待自然打开 APP，30 日复借率仅 18%（行业 30%+）。

**目标**：
- 3 个月内将结点覆盖率从 40% 提升至 90%。

---

### 痛点 3 🔴 频次失控 / 打扰度高（严重度：★★★★）

**问题描述**：
- 单日 Push 5+ 条（高峰 10+），用户关闭通知权限率高达 25%。
- 短信日均 1 - 2 条，部分用户日均 3+ 条，被列为"骚扰号"风险。
- 营销与还款提醒混发，用户无法区分"重要通知"和"广告"。

**场景佐证**：
- **场景 A**：用户 Maria 当日收到 7 条 Push：① 早上 8 点审批结果 ② 上午 10 点放款到账 ③ 中午 12 点首贷优惠 ④ 下午 2 点提额活动 ⑤ 下午 5 点还呗同类产品推荐 ⑥ 晚上 7 点抽奖活动 ⑦ 晚上 9 点"明天记得还款"。当晚她在系统设置关闭 Push 通知，并卸载 APP。
- **场景 B**：还款日 D-3 / D-1 / D0 / D+1 / D+3 / D+7 六次短信密集推送，缺少节奏感。

**业务影响**：
- 关闭通知率 25%，意味着 1/4 用户完全失联。
- 卸载率 25%（行业平均 15%），与频次正相关。
- CONDUSEF 投诉中 30% 涉及"过度通讯"。

**目标**：
- 6 个月内单日 Push 控制在 3 条以内，关闭通知率降至 10%。

---

### 痛点 4 🟠 转化率低（严重度：★★★★）

**问题描述**：
- 注册-实名转化率 35%（行业 55%），首贷转化率 12%（行业 25%），复借率 18%（行业 30%）。
- 触达效率低是核心瓶颈之一。

**场景佐证**：
- **首贷引导弱**：用户注册后没有清晰的下一步引导，仅在首页看到一个"立即借款"按钮，没有"3 步搞定、首贷优惠"的价值感传达。
- **审批中焦虑**：用户提交申请后无任何触达安抚，30% 用户在 2 分钟内离开 APP。
- **复借动机弱**：还款成功后仅收到"还款成功"通知，没有"复借红包"或"老客专属利率"等再触达。

**根因**：
- 触达内容与用户当前状态未匹配（千人一面）。
- 缺少"渐进式引导"：每个结点只触达一次，未形成"组合拳"。

**目标**：
- 注册-实名 +20pp，首贷 +13pp，复借 +12pp。

---

### 痛点 5 🟠 合规风险（严重度：★★★★）

**问题描述**：
- **营销 opt-in 收集不完整**：部分用户从未勾选营销授权，但仍在收到营销短信。
- **催收时段越界**：CONDUSEF 投诉数据显示，**8% 的催收短信发送时间在 21:00 - 9:00 之间**。
- **利率披露不充分**：部分 Push 文案仅写"低至 X 比索起"，未披露 APR。
- **ARCO 权利响应慢**：用户申请删除数据平均 7 天响应，远超 LFPDPPP 要求的 20 个工作日。

**场景佐证**：
- 用户收到"立即借款 1000 比索，5 分钟到账"Push，但未披露 CAT（年化总成本），可能被 CONDUSEF 判定为"误导性广告"。

**业务影响**：
- 每月 CONDUSEF 投诉 5 - 8 单，长期累积可能被监管约谈。
- 单一合规事件罚款 30 万 - 80 万 MXN。

**目标**：
- 6 个月内 CONDUSEF 投诉率从 0.4% 降至 0.1% 以下。

---

### 痛点 6 🟡 数据孤岛（严重度：★★★）

**问题描述**：
- 各触达通道（Push/短信/邮件/站内）独立运行，无统一的"用户今日已被触达 N 次"计数。
- 触达数据未回流到数据仓库，无法做"触达 → 行为 → 转化"全链路分析。
- A/B 测试缺乏基础设施，新策略上线后无法快速评估。

**业务影响**：
- 无法做频次控制（见痛点 3）。
- 无法做用户疲劳度建模。
- 无法精准识别"已流失 / 待流失 / 即将流失"。

**目标**：
- 3 个月内建成统一触达中台和数据回流链路。

---

### 痛点 7 🟡 缺少节日/活动运营的体系化设计（严重度：★★）

**问题描述**：
- 节日（亡灵节、Buen Fin 黑色星期五、圣诞、新年）等大流量节点运营高度依赖临时拍脑袋。
- 缺少"节日触达日历"和"活动触达 SOP"。

**业务影响**：
- Buen Fin、圣诞等节点本应拉新 50%+ 增长，但因触达设计粗糙，仅实现 15 - 20% 增长。

## 3. 用户调研数据支撑（线下访谈 30 名用户 + 1000 份问卷摘要）

### 3.1 触达偏好调研
| 触达形式 | 用户接受度 | 干扰度 | 信任度 | 综合评分 |
|---|---|---|---|---|
| APP Push | 78% | 4.2/5 | 4.0/5 | ⭐⭐⭐⭐ |
| 短信 | 85% | 3.0/5 | 4.5/5 | ⭐⭐⭐⭐ |
| WhatsApp | 92% | 2.5/5 | 4.6/5 | ⭐⭐⭐⭐⭐ |
| 邮件 | 35% | 1.5/5 | 4.8/5 | ⭐⭐⭐ |
| 站内 IM | 70% | 1.8/5 | 4.4/5 | ⭐⭐⭐⭐ |
| 弹窗 | 60% | 4.5/5 | 3.5/5 | ⭐⭐ |
| 横幅 | 65% | 2.0/5 | 3.8/5 | ⭐⭐⭐⭐ |
| Toast 浮窗 | 75% | 1.5/5 | 4.2/5 | ⭐⭐⭐⭐⭐ |
| 电话催收 | 22% | 5.0/5 | 3.2/5 | ⭐ |
| 桌面角标 | 50% | 2.5/5 | 3.5/5 | ⭐⭐⭐ |

> **核心结论**：用户对"低干扰 + 高信息量"的形式（WhatsApp / Toast / 短信）接受度最高；对"强制打断"形式（电话催收 / 全屏弹窗）反感最强。

### 3.2 关键调研洞察
- 💡 78% 用户希望"还款提醒"提前 3 天收到 1 次 + 前 1 天再 1 次就够，不需要 D+1 / D+3 / D+7 反复提醒。
- 💡 65% 用户在还款成功后愿意接受"复借红包"推送，但需要清楚标注"可选"。
- 💡 88% 用户在遇到问题时第一反应是"找 APP 内客服"，但目前 APP 客服入口深、响应慢。
- 💡 55% 用户表示"如果 APP 频繁发无关营销，会关闭通知甚至卸载"。
- 💡 90% 用户希望"重要通知"和"营销"在视觉上明确区分（如图标、颜色）。

## 4. 痛点优先级与改进目标

| 痛点 | 严重度 | 改进目标（6 个月） | 优先级 |
|---|---|---|---|
| 1. 形式单一 | ★★★★★ | 触达形式扩至 10+ 种，单一渠道占比 ≤ 50% | P0 |
| 2. 结点不全 | ★★★★★ | 结点覆盖率 40% → 90% | P0 |
| 3. 频次失控 | ★★★★ | 单日 Push ≤ 3 条，关闭通知率 -15pp | P0 |
| 4. 转化率低 | ★★★★ | 转化率指标 +10 - 20pp | P1 |
| 5. 合规风险 | ★★★★ | 投诉率 0.4% → 0.1% | P0 |
| 6. 数据孤岛 | ★★★ | 建成统一触达中台 | P1 |
| 7. 节日运营 | ★★ | 建立节日触达 SOP | P2 |

## 5. 小结

- 当前触达体系处于"形式单一 + 结点不全 + 频次失控 + 合规风险"四重压力下，已经显著拖累业务指标。
- 用户调研显示**低干扰高信息**形式（WhatsApp / Toast / 短信）接受度最高，应作为后续方案的主轴。
- 痛点改进必须**体系化**（触达形式 + 结点 + 矩阵 + 频次 + 合规 + 数据），不能逐个击破。
- 后续 `04-产品规划与设计思路.md` 将基于这些痛点，给出 10+ 触达形式、10+ 触达结点、30+ 矩阵交叉点的完整方案。
