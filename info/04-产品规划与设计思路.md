## 1. 触达形式清单（12 种）

> 每种形式定义：**适用场景 / 文案长度 / 触发时机 / 频次限制 / 优先级 / 关闭方式 / 合规约束**。
> 优先级 P0 - P2：P0 = 必做，P1 = 重要，P2 = 锦上添花。

### 1.1 推送（Push Notification）· P0
- **适用场景**：审批结果、放款到账、还款提醒、紧急活动、流失召回
- **文案长度**：标题 ≤ 30 字符，正文 ≤ 80 字符
- **触发时机**：实时（事件触发后 ≤ 30 秒推送）
- **频次限制**：单日 ≤ 3 条/用户，单周 ≤ 10 条
- **优先级**：高（系统级通知，触达率 100%）
- **关闭方式**：用户可在系统设置或 APP"通知设置"中关闭
- **合规约束**：营销 Push 必须有 opt-in 授权；催收 Push 必须在 9:00 - 20:00

### 1.2 站内横幅（Home Banner）· P0
- **适用场景**：首页活动推广、新功能上线、提额活动
- **文案长度**：标题 ≤ 12 字，描述 ≤ 30 字，可加 1 个 CTA 按钮
- **触发时机**：用户打开 APP 展示
- **频次限制**：同时 ≤ 2 个 Banner，可滑动切换
- **优先级**：中
- **关闭方式**：右上角"X"主动关闭，"今日不再显示"
- **合规约束**：利率广告须含 CAT 和"incluye IVA"

### 1.3 模态弹窗（Modal Dialog）· P0
- **适用场景**：重要通知（如审批拒绝、协议确认、合规授权）
- **文案长度**：标题 ≤ 20 字，正文 ≤ 100 字
- **触发时机**：用户进入特定页面或满足触发条件时
- **频次限制**：单日 ≤ 1 次/用户/类型
- **优先级**：高（强制用户阅读）
- **关闭方式**：仅"确认"或"取消"，不可 X 关闭（合规类）
- **合规约束**：利率披露、协议确认、ARCO 申请必须用此形式

### 1.4 短信（SMS）· P0
- **适用场景**：还款提醒（最重要）、验证码、放款到账
- **文案长度**：单条 ≤ 160 字符（含签名）
- **触发时机**：还款前 3 天 / 1 天 / 当日，逾期 1/3/7/15/30 天
- **频次限制**：单日 ≤ 2 条/用户/类型
- **优先级**：高（用户信任度最高）
- **关闭方式**：用户回复 "STOP"（双订阅机制）
- **合规约束**：含 short code 注册；不含营销内容除非 opt-in；催收时段 9:00 - 20:00

### 1.5 邮件（Email）· P1
- **适用场景**：欢迎序列、月度账单、协议、复借邀请、活动营销
- **文案长度**：主题 ≤ 30 字符，正文无限制
- **触发时机**：注册 / 还款完成 / 月度 / 活动期
- **频次限制**：单日 ≤ 1 封/用户，单周 ≤ 3 封
- **优先级**：中
- **关闭方式**：邮件底部"取消订阅"链接
- **合规约束**：必须含公司信息、物理地址、取消订阅链接（LFPDPPP）

### 1.6 站内 IM / WhatsApp 客服 · P0
- **适用场景**：催收（最佳实践）、审批咨询、投诉处理
- **文案长度**：单消息 ≤ 300 字符
- **触发时机**：用户在 APP 内发起咨询 / 自动催收触发
- **频次限制**：催收 IM 单日 ≤ 2 条/用户
- **优先级**：高（双向沟通）
- **关闭方式**：用户主动结束会话或屏蔽
- **合规约束**：WhatsApp 须用 Business API；催收时段 9:00 - 20:00

### 1.7 Toast 浮窗 · P0
- **适用场景**：操作反馈（绑卡成功、还款成功）、轻量提示
- **文案长度**：≤ 30 字
- **触发时机**：用户操作完成后 ≤ 1 秒
- **频次限制**：单页面 ≤ 1 条/操作
- **优先级**：低
- **关闭方式**：自动消失（3 - 5 秒）
- **合规约束**：无

### 1.8 Slide-up 抽屉（半屏弹层）· P1
- **适用场景**：提额活动落地、复借邀请、运营活动
- **文案长度**：标题 ≤ 20 字，描述 ≤ 60 字 + 1 个 CTA
- **触发时机**：用户进入首页 / 个人中心 / 还款完成
- **频次限制**：单日 ≤ 1 次/用户
- **优先级**：中
- **关闭方式**：可下滑关闭 / 顶部"X"
- **合规约束**：利率披露、活动截止日期

### 1.9 引导蒙层（Coach Mark / Onboarding Mask）· P1
- **适用场景**：新功能引导、首贷 3 步引导、隐私设置说明
- **文案长度**：单步骤 ≤ 50 字 + 插画
- **触发时机**：首次进入新功能时
- **频次限制**：每功能仅展示 1 次（可设置"再看一次"）
- **优先级**：中
- **关闭方式**："知道了"按钮或蒙层外点击
- **合规约束**：隐私设置、ARCO 权利说明须用此形式

### 1.10 状态栏 / 桌面角标（Badge）· P0
- **适用场景**：未读消息数、待还款数、待办任务数
- **文案长度**：纯数字（99+ 上限）
- **触发时机**：状态变化实时更新
- **频次限制**：不限
- **优先级**：低
- **关闭方式**：用户清除未读自动消失
- **合规约束**：无

### 1.11 运营浮窗（Floating Widget）· P1
- **适用场景**：常驻活动入口、客服入口、AI 助手入口
- **文案长度**：图标 + 标签（≤ 6 字）
- **触发时机**：APP 内常驻
- **频次限制**：同时 ≤ 1 个
- **优先级**：中
- **关闭方式**：用户长按可关闭 24 小时
- **合规约束**：客服浮窗可展示服务时间

### 1.12 桌面 Widget（小部件）· P2
- **适用场景**：iOS 锁屏小组件 / Android 桌面，显示余额、待还款
- **文案长度**：极简（数字 + 短标签）
- **触发时机**：实时刷新
- **频次限制**：用户主动添加
- **优先级**：低
- **关闭方式**：用户删除
- **合规约束**：无

## 2. 触达结点清单（12 个用户生命周期结点）

> 每个结点定义：**用户状态 / 目标 / 触达内容 / 推荐触达形式 / 转化目标 / 成功指标**。

### 结点 1 · 注册成功
- **用户状态**：刚完成手机号注册，未实名
- **目标**：引导完成实名认证（KYC）
- **触达内容**：欢迎语 + 实名奖励 + 3 步引导
- **推荐形式**：Push + 引导蒙层 + 邮件欢迎信 + 站内横幅
- **转化目标**：实名认证转化率 ≥ 60%
- **成功指标**：注册-实名转化率、首贷时间（TTF）

### 结点 2 · 实名引导
- **用户状态**：已注册，未完成 INE + 自拍 + 地址验证
- **目标**：完成实名认证，进入风控流程
- **触达内容**：分步引导（先传 INE → 再自拍 → 最后地址）
- **推荐形式**：Push（24h 未完成时） + 引导蒙层 + 站内 IM 引导 + 短信（D+1 提醒）
- **转化目标**：实名认证完成率 ≥ 80%
- **成功指标**：实名完成率、单步流失率

### 结点 3 · 绑卡引导
- **用户状态**：已实名，未绑卡
- **目标**：完成银行卡绑定（SPEI 或 OXXO）
- **触达内容**：绑卡教程 + 安全保障说明
- **推荐形式**：Slide-up 抽屉 + 引导蒙层 + Toast 进度反馈 + 短信（D+2）
- **转化目标**：绑卡完成率 ≥ 75%
- **成功指标**：绑卡完成率、绑卡方式分布

### 结点 4 · 风控审核中
- **用户状态**：提交申请，等待风控决策
- **目标**：安抚用户焦虑、降低跳出率
- **触达内容**：进度条可视化 + 预计时长 + 客服入口
- **推荐形式**：状态条（APP 内） + Toast 实时刷新 + 邮件（长时间审核） + IM 客服
- **转化目标**：审核期间留存率 ≥ 70%
- **成功指标**：审核期间 APP 停留时长、二次进入率

### 结点 5 · 审批结果
- **用户状态**：审批通过或拒绝
- **目标**：通过时引导放款，拒绝时引导查看原因和改善路径
- **触达内容**：结果通知 + 下一步建议
- **推荐形式**：Push + 模态弹窗（结果） + 邮件（通过） + 短信（拒绝）
- **转化目标**：通过 → 放款 ≥ 90%；拒绝 → 90 日复借率 ≥ 20%
- **成功指标**：放款转化率、拒绝用户 90 日复借率

### 结点 6 · 放款到账
- **用户状态**：资金已转入用户账户
- **用户情感高峰**：感知最强、推荐意愿最高
- **触达内容**：到账通知 + 还款提醒 + 推荐邀请
- **推荐形式**：Push + 模态弹窗（带分享） + 短信 + 邮件 + 站内 IM 推荐
- **转化目标**：推荐注册率 ≥ 10%
- **成功指标**：分享率、新用户邀请转化

### 结点 7 · 还款前 3 日 / 1 日 / 当日
- **用户状态**：未逾期，临近还款
- **目标**：提醒按时还款，降低逾期率
- **触达内容**：金额 + 日期 + 渠道 + 难度分级
- **推荐形式**：Push（D-3、D-1） + 短信（D-3、D-1、D0） + 站内横幅（D0） + IM（D0 主动）
- **转化目标**：D0 还款率 ≥ 60%
- **成功指标**：D0 还款率、7 日回收率

### 结点 8 · 逾期分级（轻度 1-7 天 / 中度 7-30 天 / 重度 30+ 天）
- **用户状态**：已逾期，按天数分级
- **目标**：轻度：提醒还款；中度：协商方案；重度：正式催收 + 信用影响
- **触达内容**：分级话术 + 后果提示（信用记录、法律）
- **推荐形式**：
  - 轻度（1-7 天）：Push + 短信 + IM 客服
  - 中度（7-30 天）：短信（每日 1 条） + IM（隔日） + 邮件（每周） + 电话（每 3 日 1 次）
  - 重度（30+ 天）：短信 + IM + 邮件 + 电话 + 委托催收（合规备案）
- **转化目标**：7 日回收率 ≥ 88%
- **成功指标**：各阶段回收率、催收成功率

### 结点 9 · 复借邀请（D+3 / D+7 / D+15 / D+30）
- **用户状态**：已还款成功，处于沉默期
- **目标**：激活复借，提升 LTV
- **触达内容**：复借红包 + 老客利率 + 快速通道
- **推荐形式**：Push（D+3、7、15、30） + 站内横幅 + 邮件 + 短信（D+15、30） + Slide-up 抽屉
- **转化目标**：30 日复借率 ≥ 30%
- **成功指标**：30/60/90 日复借率

### 结点 10 · 流失召回（30 / 60 / 90 天未登录）
- **用户状态**：连续未活跃
- **目标**：召回流失用户
- **触达内容**：关怀 + 福利（提额、利率折扣）
- **推荐形式**：
  - 30 天：Push + 邮件 + 短信
  - 60 天：Push + 邮件 + 短信 + IM
  - 90 天：短信 + 邮件（最后触达）+ 站内 IM
- **转化目标**：流失召回率 ≥ 15%
- **成功指标**：各阶段召回率、召回用户 30 日活跃度

### 结点 11 · 提额 / 活动期
- **用户状态**：可提额（信用良好）、活动命中（生日、节日）
- **目标**：提额引导、活动转化
- **触达内容**：提额额度 + 利率 + 活动福利
- **推荐形式**：运营浮窗 + Slide-up 抽屉 + 横幅 + Push + 短信（重大活动） + 邮件
- **转化目标**：提额使用率 ≥ 50%
- **成功指标**：提额申请率、活动 GMV

### 结点 12 · 合规 opt-in 授权
- **用户状态**：首次启动 / 营销授权未勾选
- **目标**：合规收集用户授权
- **触达内容**：透明说明 + 权限分类 + 一键开启
- **推荐形式**：引导蒙层 + 模态弹窗 + 设置入口 + 邮件确认 + 站内 IM
- **转化目标**：授权完整率 ≥ 95%
- **成功指标**：授权完整率、用户对授权的理解度

## 2.5 扩展触达结点（信贷核心流程深度挖掘 · 12 → 24）

> **v1.1 增量**：v1.0 定义了 12 个核心触达结点（注册→放款→还款→逾期→复借→召回→提额→opt-in）。v1.1 在信贷核心流程中**深挖 12 个补充结点**，覆盖贷前/贷中/贷后/运营/合规 5 大场景类型。合计 **24 个结点**，与 12 触达形式可生成 **288 个矩阵交叉点**。

### 13 · 资料补充引导（INSUFFICIENT_DOCS）
- **用户状态**：申请贷款时风控提示资料不足（如 INCOME_PROOF / ADDRESS_VERIFICATION / BANK_STATEMENT）
- **目标**：补全资料推进审批
- **触达内容**：缺什么 + 为什么需要 + 如何上传（3 步蒙层）
- **推荐形式**：引导蒙层 + 模态弹窗 + 短信（D+1 提醒）+ IM 协助
- **转化目标**：补全率 ≥ 70%
- **成功指标**：补全率、单步流失率

### 14 · 提额待激活（PENDING_LIMIT_ACTIVATION）
- **用户状态**：系统批准提额（如 5,000 → 15,000 MXN），但用户未确认激活
- **目标**：让用户激活新额度
- **触达内容**：新额度数字 + 利率 + 激活按钮
- **推荐形式**：模态弹窗（强） + Push + 站内横幅 + 短信（D+3 未激活）
- **转化目标**：激活率 ≥ 60%
- **成功指标**：激活率、激活到首次使用时长

### 15 · 优惠券到期前（D-3 临期）
- **用户状态**：持有未用券，剩 ≤ 3 天到期
- **目标**：促进券核销（与项目 2 联动）
- **触达内容**：券信息 + 过期时间 + 使用场景
- **推荐形式**：Push + 站内横幅 + 模态弹窗 + 短信（关键券）
- **转化目标**：临期券核销率 ≥ 55%
- **成功指标**：临期券核销率、与常规券核销率对比

### 16 · 绑卡失败重试（PAYMENT_METHOD_FAIL）
- **用户状态**：绑卡时扣款失败（卡号错误/CVV 错/卡过期/余额不足）
- **目标**：引导重试，减少绑卡流失
- **触达内容**：失败原因 + 重试入口 + 替代方案（SPEI/OXXO）
- **推荐形式**：Toast + 模态弹窗（错误详情） + 引导蒙层 + IM 协助
- **转化目标**：重试成功率 ≥ 50%
- **成功指标**：绑卡完成率、错误类型分布

### 17 · 还款扣款失败（REPAY_FAIL）
- **用户状态**：自动扣款日扣款失败（余额不足/银行拒绝/限额）
- **目标**：挽救逾期，避免上征信
- **触达内容**：失败原因 + 立即还款入口 + 替代支付方式
- **推荐形式**：Push（强） + 短信（强） + 站内 IM + 模态弹窗
- **转化目标**：D+1 内补还率 ≥ 80%
- **成功指标**：扣款成功率、逾期转化率

### 18 · 信用分变化（CREDIT_SCORE_CHANGE）
- **用户状态**：完成按时还款后，信用分 +15-+30
- **目标**：正向激励，强化按时还款习惯
- **触达内容**：新分数 + 提升幅度 + 下一档权益
- **推荐形式**：模态弹窗（庆祝） + Push + 邮件
- **转化目标**：激励有效率 ≥ 60%（看到后下次继续按时）
- **成功指标**：信用分提升用户 90 日还款率

### 19 · 生日 / 注册周年（BIRTHDAY / ANNIVERSARY）
- **用户状态**：用户生日 / 注册周年
- **目标**：情感连接 + 复借激活
- **触达内容**：祝福语 + 专属福利（提额券/利率券）
- **推荐形式**：模态弹窗 + Push + 短信 + 邮件（长内容）
- **转化目标**：当日活跃率 ≥ 40%
- **成功指标**：当日活跃、复借率

### 20 · 紧急联系人未设置（EMERGENCY_CONTACT_MISSING）
- **用户状态**：未设置紧急联系人（合规 + 风控要求）
- **目标**：引导设置
- **触达内容**：为什么需要 + 隐私说明 + 设置入口
- **推荐形式**：引导蒙层（首次大额借款前） + 模态弹窗
- **转化目标**：设置率 ≥ 85%
- **成功指标**：设置率、逾期联系成功率

### 21 · 额度使用率过高（HIGH_UTILIZATION）
- **用户状态**：当前借款余额 / 总额度 ≥ 80%
- **目标**：风险预警，避免多头借贷
- **触达内容**：使用率提示 + 还款建议 + 暂停借款建议
- **推荐形式**：Push（限 1 次） + 站内横幅 + 模态弹窗（申请时强制）
- **转化目标**：风险提示后 7 日内还款率 ≥ 30%
- **成功指标**：多头借贷转化率

### 22 · 推荐奖励到账（REFERRAL_BONUS_RECEIVED）
- **用户状态**：邀请的好友放款成功，自己的奖励入账
- **目标**：即时反馈 + 激励继续邀请
- **触达内容**：奖励金额 + 好友名字 + 再邀请按钮
- **推荐形式**：模态弹窗（庆祝） + Push + 站内 IM

### 26 · 放款状态触达（LOAN_STATUS）
- **用户状态**：放款全流程 — 待初审/初审中/初审驳回/初审通过/复审驳回/复审通过/放款中/放款失败/已放款
- **目标**：放款进度透明化、失败可挽救、合规可追溯
- **触达内容**：当前状态 + 预计时长 + 失败原因 + 重试/换绑卡入口
- **推荐形式**：站内状态条（核心） + Push（关键节点） + 短信（失败） + IM（限额等待）
- **关键状态码**（源自流程图）：

| 状态码 | 含义 | 触达策略 |
|---|---|---|
| **status=0 待机审** | 风控未处理 | 状态条 + 预计时间 + 客服入口 |
| **status=2 初审中** | 机审进行中 | 状态条 + 进度提示 + 节假日可加期 |
| **status=-3 初审驳回** | 机审拒绝 | 拒绝原因 + 改善建议 + 申诉入口 |
| **status=1 初审通过** | 准备放款 | 庆祝动效 + 推荐分享 + 邀请券 |
| **status=-4 复审驳回** | 人审拒绝 | 详细原因 + 客服入口 + 30 日复借可能 |
| **status=20 复审通过** | 待放款 | 自动放款中 + 限额等待告知 |
| **status=-5 放款驳回** | 放款被拒 | 原因 + 换绑卡 + 重试入口 |
| **status=22 放款中** | 调用支付 | 状态条 + 实时刷新 + 2min 轮询 |
| **status=-10 放款失败** | 渠道失败 | 失败类型 + 换绑卡（可/不可）+ 客服 |
| **status=21 已放款** | 成功 | 庆祝弹窗 + 还款提醒 + 邀请红包 |

- **合规联动**：实名撞脸（100）→ 放款同步拒绝，复审放款失败（-5）+ 实名驳回（12/13/14）联动
- **转化目标**：放款失败后 24h 内换绑卡成功率 ≥ 50%；复审驳回后 30 日复借率 ≥ 20%
- **成功指标**：放款成功率、失败类型分布、复借率

## 4. 设计原则

### 4.1 打扰度-有效性平衡
- **3 层漏斗**：营销层（横幅 / 浮窗 / Slide-up）→ 提醒层（Push / Toast）→ 强提醒层（短信 / 模态）
- **优先级规则**：同一事件，先弱后强；用户连续 3 天关闭同一类通知，自动降级
- **时段规则**：所有非紧急触达在 9:00 - 21:00，紧急触达（逾期）也限制 9:00 - 20:00

### 4.2 A/B 测试框架
- **流程**：假设 → 设计变体 → 流量分配（10% / 50% / 100% 灰度）→ 指标对比 → 全量
- **最小样本量**：每组 ≥ 1000 用户
- **核心实验维度**：
  - 文案风格（理性 vs 情感）
  - 触达时机（D-3 vs D-2）
  - 频次（单日 1 条 vs 2 条）
  - 形式组合（Push only vs Push + 短信）
  - 视觉（图标 / 颜色 / 动画）
- **实验评估周期**：≥ 7 天，覆盖完整工作日和周末
- **决策门槛**：统计显著性 ≥ 95%，业务提升 ≥ 5%

### 4.3 频次控制（防骚扰）
- **单日上限**：
  - Push ≤ 3 条/用户
  - 短信 ≤ 2 条/用户
  - 邮件 ≤ 1 封/用户
  - 站内弹窗（合并）≤ 2 次/用户
- **7 日滑动窗口**：累计触达 ≤ 15 次/用户（Push + 短信 + 邮件 + 弹窗 + IM 合并）
- **跨渠道去重**：同一内容不在多渠道重复发送（除非用户未打开 Push 后 24h，再发短信）
- **疲劳度模型**：用户 7 日内关闭通知 ≥ 2 次，自动暂停营销类触达 14 日
- **沉默用户保护**：连续 30 日未打开 APP，自动停止 Push，仅保留短信

### 4.4 防骚扰策略
- **退订一键化**：每条营销 Push 含"Dejar de recibir"、每封邮件底部含 unsubscribe 链接
- **用户偏好中心**：APP"设置-通知偏好"可细分（还款 / 活动 / 复借 / 提额）4 类，每类独立开关
- **夜间静默**：21:00 - 9:00 仅紧急催收可发，其他全部延后
- **节假日策略**：墨西哥法定节假日（独立日 9/16、亡灵节 11/1-2、圣诞 12/25 等）非催收触达延后到工作日
- **投诉响应**：用户 1 次投诉 → 立即暂停所有营销 30 日 + 触发人工客服

### 4.5 灰度发布机制
- **发布层级**：1% → 5% → 20% → 50% → 100%，每级至少 24h 观察
- **分层维度**：用户群（新/老）、城市、机型、信用等级
- **熔断机制**：当新策略触发关闭通知率 +5pp 或卸载率 +2pp，自动回滚
- **回滚 SLA**：发现问题 30 分钟内回滚

### 4.6 个性化与人群分层
- **核心人群**：新用户（D0 - 7）、活跃用户（D8 - 30）、沉默用户（D31+）、流失用户（D60+）
- **行业分层**：蓝领 / 学生 / 中产 / 自由职业
- **行为分层**：高频借款 / 中频 / 低频 / 偶发
- **触达策略差异化**：不同人群不同频次上限和内容偏好
